## 功能

- 任一欄位查詢：採購案號、廠商編號、廠商簡稱、商品條碼、商品名、需求商品名、規格、計量單位、售價、契約價、決標價、起供日、備註、代理商
- 篩選：採購案、廠商、代理商、品類、計量單位、售價區間、資料完整度
- 決標價：依得標廠商的決標項次下拉選取
- 計價規則：契約價 = 決標價/100g × 重量(g) ÷ 100（算到小數第二位，以下捨去）；售價 = 契約價 × 1.05（無條件進位到個位），並自動核對售價表
- 匯出 CSV

## 填寫資料存放位置

在 GitHub Pages 上，決標價選擇、產品照、備註、代理商等填寫資料只存在**使用者自己的瀏覽器**（IndexedDB），不會上傳，也不會與他人同步。換電腦或清除瀏覽器資料前，請先按「備份填寫資料」存成 JSON，之後可用「匯入備份」還原或分享給同事。
